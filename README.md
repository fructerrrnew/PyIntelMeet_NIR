# PyIntelMeet

**Интеллектуальная платформа видеоконференций** с RAG-коррекцией транскрипции по базе знаний и автоматической генерацией структурированных отчётов.

Простой рабочий прототип, разработанный в рамках НИР в НИУ «МЭИ».

## Быстрый запуск (3 минуты)

### Шаг 1. Клонирование
```bash
git clone https://github.com/fructerrrnew/PyIntelMeet_NIR.git
cd PyIntelMeet
```

### Шаг 2. Виртуальное окружение (рекомендуется)
```bash
python -m venv .venv

# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1

# Linux / macOS:
source .venv/bin/activate
```

### Шаг 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

> **Windows**: Если при установке возникнут ошибки — установите [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/).

### Шаг 4. Запуск
```bash
python main.py
```

Откройте в браузере:  
**http://127.0.0.1:8000**

---

## Как быстро посмотреть, что всё работает

1. На главной странице нажмите **«Демо-комната»**
2. Подождите 2–3 секунды — загрузится пример совещания с техническими терминами
3. Нажмите **«Завершить встречу»**
4. Система автоматически:
   - исправит ошибки распознавания через базу знаний (RAG)
   - сгенерирует структурированный отчёт
   - покажет его в новом окне

## Дополнительно (по желанию)

### Ollama — умные отчёты с помощью ИИ
Если хотите, чтобы отчёты генерировались не эвристикой, а языковой моделью:

1. Установите [Ollama](https://ollama.com/)
2. Скачайте модель:
   ```bash
   ollama pull qwen2.5:7b
   ```
3. Запустите PyIntelMeet — система сама найдёт Ollama.

### Проверка состояния системы
Откройте: http://127.0.0.1:8000/health

## Возможности системы

- P2P видеоконференции (WebRTC)
- Живые субтитры на русском языке
- Коррекция технической терминологии через базу знаний (RAG)
- Автоматическая генерация отчётов (timeline + решения + задачи)
- История всех встреч и отчётов
- Демонстрационный режим с готовым примером
